# Tessera course — authoring guide

This is a [Tessera](https://www.npmjs.com/package/tessera-learn) course. The full
authoring guide — components, hooks, course structure, LMS export, accessibility —
ships with the framework. Run `pnpm install`, then read it at
`node_modules/tessera-learn/AGENTS.md` before generating or editing course content.

@./node_modules/tessera-learn/AGENTS.md

The guide always matches your installed `tessera-learn` version, so there's
nothing to keep in sync here.
